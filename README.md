# Customer Data Cleaning & Automated Reporting

## Project Overview

This project is a Python-based automation system for cleaning, validating, and reporting customer data stored in Excel.

The system reduces manual data-cleaning work by automatically checking customer records and generating a professional Excel report.

## What This Project Does

- Detects duplicate email addresses
- Standardizes country names
- Checks phone number quality
- Identifies records that need review
- Generates data-quality summaries
- Creates an automated Excel report
- Generates charts for data analysis

## Technologies Used

- Python
- Pandas
- OpenPyXL
- Microsoft Excel
